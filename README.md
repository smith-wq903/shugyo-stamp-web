# 修行（しゅぎょう）スタンプ — ブラウザ完結版

サーバー不要・PC不要のブラウザ完結型アプリです。
iPad のブラウザだけで動作し、データは端末内（IndexedDB）に保存されます。

## 機能

- **月カレンダー表示** — 前月・次月をナビゲーション
- **複数教科のスタンプ管理** — 教科ごとにスタンプ（⭐🌟💮🎉💯）を選んで記録
- **教科の追加・削除・名前変更** — ⚙️ 設定画面から管理
- **修行リマインダー** — 設定した時間帯にアプリを開くとバナー表示
- **連続日数カウント** — 全教科完了の連続日数を表示
- **エクスポート / インポート** — JSONファイルでデータのバックアップ・復元
- **iPad 対応** — タッチフレンドリーな大きめ UI
- **オフライン動作** — ネットワーク不要

## 必要環境（開発時のみ）

- Node.js v18 以上

## セットアップ

```bash
cd shugyo-stamp-web
npm install
```

## 開発サーバーで動かす

```bash
npm run dev
```

ブラウザで **http://localhost:5173** を開きます。
iPad からは `http://<PCのIP>:5173` でアクセスできます。

## 本番ビルド（静的ファイル生成）

```bash
npm run build
```

`dist/` フォルダに HTML/CSS/JS が生成されます。
この `dist/` の中身を任意のホスティングにアップロードすれば公開できます。

### 無料ホスティング例

- **GitHub Pages** — `dist/` を GitHub リポジトリにプッシュして公開
- **Netlify / Vercel** — リポジトリを接続して自動デプロイ

## 動作確認手順

1. `npm run dev` を実行
2. ブラウザで **http://localhost:5173** を開く
3. カレンダーが表示されることを確認
4. 日付をタップ → 教科ごとにスタンプを選んで「ほぞん」
5. ⚙️ → 教科の追加・削除・名前変更ができることを確認
6. ⚙️ →「📤 エクスポート」→ JSONファイルがダウンロードされることを確認
7. ⚙️ →「📥 インポート」→ ダウンロードしたJSONを読み込んでデータが復元されることを確認

## データについて

- データは**ブラウザの IndexedDB** に保存されます
- アプリを更新してもデータは消えません
- Safari の「履歴とWebサイトデータを消去」を行うとデータが消えるため、定期的なエクスポートを推奨します

## 旧版（サーバー版）との違い

| 項目 | サーバー版 (homework-stamp) | ブラウザ版 (本アプリ) |
|------|---------------------------|---------------------|
| サーバー | Express + SQLite 必要 | 不要 |
| データ保存先 | PC上のSQLiteファイル | ブラウザ内 IndexedDB |
| PC依存 | あり（常時起動必要） | なし |
| オフライン | 不可 | 可能 |
